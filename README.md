# Лабораторні роботи №5, №6 та №7

**Дисципліна:** Технології розробки програмного забезпечення (ТРПЗ)  
**Виконала:** Осокіна Анастасія  
**Група:** ІСТ-24-1  
**Варіант:** 5

## Опис проєкту

Репозиторій містить результати виконання лабораторних робіт із використанням фреймворку Ruby on Rails.

## Лабораторна робота №5 (2.3–2.4)

- Створення вебзастосунку інтернет-магазину.
- Створення моделей та контролерів.
- Реалізація CRUD-операцій.
- Робота з Active Record та SQLite.
- Створення міграцій і зв'язків між моделями.

## Лабораторна робота №6 (2.5–2.6)

- Налаштування маршрутизації та контролерів.
- Створення статичних і динамічних сторінок.
- Створення форм та обробка параметрів.
- Підключення Bootstrap.
- Валідація даних.

## Лабораторна робота №7 (2.7)

- Підключення бібліотеки Devise.
- Створення моделі User.
- Реєстрація та аутентифікація користувачів.
- Оформлення форм входу, реєстрації та відновлення пароля.

## Структура репозиторію

- `online_store/` — основний вебзастосунок інтернет-магазину.
- `rails_lab6_test/` — додатковий тестовий застосунок лабораторної роботи №6.

## Використані технології

Ruby, Ruby on Rails, SQLite, Active Record, HTML, CSS, Bootstrap, Devise, Git та GitHub.

## Запуск проєкту

Перейти до папки відповідного застосунку та виконати команди:

- `bundle install`
- `ruby bin/rails db:prepare`
- `ruby bin/rails server`

Вебзастосунок доступний за адресою http://localhost:3000.
